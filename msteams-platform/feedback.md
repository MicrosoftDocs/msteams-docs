# Support and feedback for Teams developers

Use this page to find the right place to get help or share feedback while building agents and apps for Microsoft Teams.

## Get help and share feedback

Developer support and feedback for the Teams platform goes through the [Teams SDK repository](https://github.com/microsoft/teams-sdk) on GitHub.

| I want to... | Go to |
| --- | --- |
| **Report an issue or send feedback** | [Teams SDK › Issues](https://aka.ms/TeamsDeveloperFeedback) |
| **Request a feature** | [Teams SDK › Discussions › Ideas / Feature requests](https://aka.ms/TeamsDeveloperFeatureRequest) |
| **Ask a question** | [Teams SDK › Discussions › Q&A](https://aka.ms/TeamsDeveloperQuestion) |

## Before you post

- Search the [Teams platform documentation](/microsoftteams/platform/).
- Search [existing issues](https://github.com/microsoft/teams-sdk/issues) and [discussions](https://github.com/microsoft/teams-sdk/discussions) to avoid duplicates. Add a comment or a reaction to an existing post instead of opening a new one.

## What to include in an issue

- Teams SDK language and version
- Steps to reproduce
- Expected result and actual result
- Error message and request or correlation ID, if available

> [!IMPORTANT]
> Don't include secrets, tokens, credentials, or tenant data in issues or discussions. Repository content is public.

## What happens next

- A Microsoft support team reviews new issues and discussions.
- If the documentation answers your question, you'll get a link to the relevant article.
- Bugs and feature requests are logged and shared with the owning product teams.
- GitHub issues and discussions don't include guaranteed response times. For business-critical issues, use the [paid support options](#business-critical-and-paid-support).

## Business-critical and paid support

| Scenario | Where to go |
| --- | --- |
| **Microsoft Teams service issues and failures** | If you have a support contract for Microsoft 365, open a service request from the **Support** menu in the [Microsoft 365 admin center](https://admin.microsoft.com). |
| **Azure services** | If you have a paid Azure subscription, create a support request in the [Azure portal](https://portal.azure.com). |
| **App submission and publishing** | For Partner Center issues, such as app submission, account setup, or publishing workflows, use the [Partner Center AI Assistant](/partner-center/support/report-problems-with-partner-center#contact-support-using-partner-center-ai-assistant). |
