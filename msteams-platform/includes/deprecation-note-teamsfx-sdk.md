>[!IMPORTANT]
>
> TeamsFx SDK is no longer supported by Microsoft for building Microsoft 365 Copilot extensions, Microsoft 365 agents, or modern Teams app scenarios. New development should not use TeamsFx. The SDK is currently in deprecation mode and will receive community-only support on GitHub until September 2026.
>
> For all new Teams agent and app development, use [Teams SDK and the Teams developer CLI](/microsoftteams/platform/teams-ai-library/welcome).
