# Code samples

[OfficeDev/Microsoft-Teams-Samples](https://github.com/OfficeDev/Microsoft-Teams-Samples) is the official Teams code samples repository on GitHub.

The GitHub repository for each Teams SDK language implementation includes feature-focused, language-specific code samples:

- [TypeScript](https://github.com/microsoft/teams.ts/tree/main/examples)
- [Python](https://github.com/microsoft/teams.py/tree/main/examples)
- [C#](https://github.com/microsoft/teams.net/tree/main/samples)
